支持自部署、多端同步与极高自由度的插件扩展。真正做到**数据私有，痕迹归己**。

## 🌟 关于 Wolog

**吾录（Wolog）= 吾（我）+ Log（记录/轨迹）** 在碎片化的数字时代，我们的生活痕迹散落各处：记账 App、备忘录、浏览器历史、运动健康……
Wolog 旨在打破数据孤岛，将你在现实与互联网上的所有痕迹，统一挂载到一条清晰的「时间轴」上。让每一笔开销、每一次深思、每一段足迹，都有处可存，有据可查。

### 核心理念

- **时间即分类**：摒弃繁琐的手动分类，所有信息天然按时间戳归档。
- **数据绝对掌控**：本地存储优先，支持跨端同步，不依赖任何第三方闭源云服务。
- **万物皆可 Plugin**：从「今日收支」到「GitHub Commit」，通过插件接入一切。

## ✨ 核心特性（开发中）

- 📅 **双核心视图**：提供日/周/月日历视图与无限滚动的纯净时间轴，直观回顾人生轨迹。
- 🧩 **全能插件架构**：一套插件 API 即可打通 Web/桌面/移动端。自由扩展数据源（如：健身打卡、读书进度、API 自动抓取）。
- 💻 **一处代码，三端运行**：基于 Web 技术栈，无缝编译为 Windows/macOS/Linux 桌面端与 Android/iOS 原生应用。
- 🔒 **隐私与加密**：支持 SQLite 纯单机模式或 PostgreSQL 自建同步，核心敏感数据支持端到端加密。
- 🎨 **原子化极简设计**：基于 Tailwind CSS 深度定制，支持深/浅色模式无缝切换，插件界面与主干风格高度统一，无冗余代码。

## 🛠 技术栈

- **核心框架**: Vue 3 + TypeScript + Vite
- **状态与路由**: Pinia + Vue Router 4
- **样式框架**: Tailwind CSS (原子化 CSS，极致轻量与自由)
- **无界面组件 (可选)**: Headless UI / Radix Vue (处理复杂无障碍交互)
- **多端容器**: Electron (Desktop) / Capacitor (Mobile)
- **本地存储**: SQLite (Local First) / 文件系统 (附件)

## 📥 快速开始

本项目目前处于 **Active Development (初期搭建)** 阶段。

```bash
# 1. 克隆仓库
git clone [https://github.com/joseplin0/wolog.git](https://github.com/joseplin0/wolog.git)

cd wolog

# 2. 安装依赖
npm install

# 3. 启动 Web 开发环境
npm run dev

# 构建与跨端 (待接入)
npm run electron:serve  # 启动桌面端调试
npm run build:mobile && npx cap sync # 构建移动端资源
```
