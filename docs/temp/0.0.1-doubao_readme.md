🌟 关于吾录 Wolog

**吾录（Wolog）= 吾（我）+ Log（记录/轨迹）**

读音谐音「吾录 ≈ Wo-log」，天然绑定中英文，好记不割裂。

我们常常在不同平台分散记录生活：记账在一个APP、日记在另一个工具、浏览痕迹散落在浏览器、摘抄保存在备忘录……

吾录 Wolog 旨在解决「信息分散、数据不私有、无法追溯」的问题，计划以时间为核心轴线，归集个人在现实与互联网上的所有痕迹，让每一段经历都有处可存、有据可查。

本项目目前处于开发阶段，核心功能正在逐步实现，欢迎关注进度、提出建议或参与开发。

- 计划记录：日常收支、活动行程、随笔感想、文章摘抄、浏览足迹等

- 核心思路：以时间为轴，统一呈现全部生活与数字痕迹

- 核心目标：私有部署、数据自主、不依赖第三方云服务

✨ 规划功能（开发中）

以下为项目核心功能规划，目前正逐步开发实现，具体进度可查看 Project。

📅 时间轴 + 日历双核心视图

- 支持日/周/月三种视图切换，点击日期快速查看当日所有记录

- 时间轴按时间顺序滚动展示，直观回顾人生轨迹

- 所有信息天然按时间归档，无需手动分类整理

🧩 插件化架构，自由扩展

- 支持插件扩展数据类型（如健身记录、读书进度、社交足迹）

- 插件可新增录入表单、展示面板、数据同步源

- 一套插件代码，全端（Web/桌面/移动端）共用，无需单独适配

💻 一套代码，三端运行

- Web端：适配现代浏览器，无需安装，直接访问

- 桌面端：基于Electron，支持Windows/macOS/Linux

- 移动端：基于Capacitor，打包为Android/iOS原生APP

- 业务逻辑100%复用，仅需少量平台适配代码

🔒 私有部署，数据自持

- 支持本地存储（SQLite）或自建数据库（PostgreSQL）

- 不依赖第三方云服务，数据不上传，隐私完全可控

- 支持数据加密存储，保护敏感信息（如记账、随笔）

🎨 主题统一，视觉舒适

- 内置深色/浅色主题，自动适配系统偏好

- 全程使用CSS变量，插件样式与主题自动同步，无视觉割裂

- 简洁克制的UI设计，专注记录本身，无多余干扰

📊 多维度检索与分析

- 支持按类型、标签、时间范围快速筛选记录

- 全文检索功能，快速找到所需内容

- 内置基础统计分析，可视化展示消费、活动、学习等数据趋势

🛠 技术栈（规划）

前端 & 多端

- 核心框架：Vue 3 + TypeScript

- 构建工具：Vite

- 桌面端：Electron

- 移动端：Capacitor

- 状态管理：Pinia

- UI组件库：Vuetify 3（响应式+主题支持）

- 路由管理：Vue Router 4

后端 & 存储

- 服务端：Node.js + Express（轻量自部署）

- 数据库：SQLite（默认，单机部署）/ PostgreSQL（多端同步）

- 存储扩展：本地文件存储（附件、截图）

架构理念

- 核心逻辑与平台解耦，保证多端复用

- 插件系统标准化，降低扩展门槛

- 数据模型统一，基于时间轴实现全信息归集

- 样式统一基于CSS变量，实现主题无缝适配

📥 开发环境搭建

本项目目前处于开发初期，尚未发布稳定版本，以下为本地开发环境搭建步骤，供开发者参考。

前置条件

- Node.js ≥ 16.0.0

- npm ≥ 7.0.0 或 yarn ≥ 1.22.0

- Git（用于拉取代码）

- 移动端打包需额外安装Android Studio / Xcode（可选）

1. 拉取代码

# 克隆仓库

git clone https://github.com/your-username/wolog.git
cd wolog

# 安装依赖

npm install

# 或

yarn install

2. 运行开发环境

Web端开发

npm run dev

# 或

yarn dev

打开浏览器访问：http://localhost:5173（当前仅展示基础界面，核心功能待开发）

桌面端开发

npm run electron:serve

# 或

yarn electron:serve

移动端开发

# 先构建Web资源

npm run build:mobile

# 或

yarn build:mobile

# 同步到Capacitor

npx cap sync

# 打开Android Studio

npx cap open android

# 打开Xcode（macOS）

npx cap open ios
